# 🍕 Food Ordering App

An online Food Ordering System built with Java Swing that allows 
users to browse a menu, add items to cart, and place orders 
through a simple and interactive GUI.

## 🚀 Features
- Browse full restaurant menu
- Add / remove items from cart
- Real-time order summary with total price
- Simple and clean Java Swing GUI
- Order confirmation screen

## 🛠️ Tech Stack
- **Language:** Java
- **UI:** Java Swing
- **Storage:** File I/O / MySQL
- **IDE:** NetBeans

## ⚙️ How to Run
1. Clone the repository
```bash
   git clone https://github.com/Ashvinlodhi/Food-Ordering-App.git
```
2. Open in NetBeans
3. Run `Main.java`
4. Browse menu and place your order!
